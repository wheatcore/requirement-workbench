## 仓库约定

- 先阅读目标仓库的 `AGENTS.md`、包管理配置、现有组件和测试。仓库规则与本通用 Skill 不同时，以仓库规则为准。
- 保持改动范围与当前任务一致，优先复用现有组件、样式和状态管理方式。
- 对公共 API、复杂业务逻辑和不直观的边界条件写简洁注释；避免给显而易见的代码添加重复注释。

## 实现与验证

- 保持现有交互、类型、无障碍和响应式布局的兼容性。
- 修改代码后运行仓库已有的相关类型检查、测试或构建命令；没有对应命令时说明实际检查了什么。
- 不提交密钥、账号配置、环境文件或生成缓存。仅将当前任务需要的文件纳入提交。
